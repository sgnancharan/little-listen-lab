# Podcaster / Little Listen Lab

## Overview

Podcaster is a minimal and delightful web application that transforms user-requested topics into custom audio podcast episodes via webhook integration (such as an ngrok tunnel).

## Tech Stack

- **Framework:** TanStack Start (React 19, TanStack Router)
- **Styling:** Tailwind CSS v4, custom CSS variables (OKLCH color system)
- **Icons:** Lucide React
- **Validation:** Zod
- **Testing:** Vitest, React Testing Library
